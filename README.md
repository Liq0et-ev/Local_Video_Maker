# Local Video Maker

Локальная программа, которая превращает длинные видео из папки в готовые YouTube Shorts. Без Telegram и без интернета
(кроме первой загрузки модели Whisper): папки с видео, музыкой и результатом задаются в `config.ini`.

```
папка input ─► поиск динамики / нарезка ─► формат 9:16 ─► субтитры с подсветкой слов ─► музыка ─► папка output
```

Это локальная версия бота [Sh_Y_Pl_B](https://github.com/Liq0et-ev/Sh_Y_Pl_B) на том же ядре. Ядро собрано из репозиториев
Dinamic_Control_YouTube_Videos (хайлайты), One_Minute_Videos (нарезка), Semi_Final_Video_Redactor / Youtube_AutoTitles_Creator
(субтитры Whisper) и Background_Audio (музыка).

## Быстрый старт

Нужны Python 3.10+ и FFmpeg в `PATH` (`ffmpeg -version` и `ffprobe -version` должны работать).

```bash
python -m venv .venv
.venv\Scripts\activate          # Linux/Mac: source .venv/bin/activate
pip install -r requirements.txt
```

1. Укажите папки (любым из способов в разделе «Как указать папки» ниже): откуда брать видео, откуда музыку и куда сохранять шорты.
2. Положите длинные видео во входную папку, а mp3/wav в папку с музыкой.
3. Запустите:

```bash
python main.py
```

Программа покажет нумерованный список видео с длительностью и пометкой `done` для уже обработанных, и спросит, что делать:
`all`, `3`, `1,3,5` или `2-5`. Готовые шорты появятся в `output_dir/<имя видео>/`.

## Как указать папки

Есть четыре способа. Если задано несколько, побеждает более верхний:

| Приоритет | Способ | Пример |
|-----------|--------|--------|
| 1 | Флаги командной строки | `python main.py --input-dir D:\Raw --music-dir D:\Music --output-dir D:\Shorts` |
| 2 | Переменные в начале `main.py` | `INPUT_DIR = r"D:\Videos\Raw"`, `MUSIC_DIR = ...`, `OUTPUT_DIR = ...` |
| 3 | `config.ini`, раздел `[paths]` | `input_dir = D:\Videos\Raw` |
| — | Вопросы при запуске | `ASK_FOLDERS = True` в `main.py` или флаг `--ask-folders` |

- В `main.py` откройте блок «YOUR FOLDERS», впишите пути между кавычками `r"..."` и запускайте как обычно (в том числе кнопкой Run в VS Code).
  Пустая строка `""` значит «взять из `config.ini`». Относительные пути считаются от папки с `main.py`.
- С `ASK_FOLDERS = True` (или `--ask-folders`) программа при каждом старте спрашивает три папки, Enter оставляет текущую.
- Если входная папка не существует или пуста, в обычном терминале программа предложит ввести другую.

## Режимы

- **highlight** — из видео собирается один шорт ~60 с из самых динамичных моментов (движение, оптический поток, громкость,
  спектральный поток). Три алгоритма: `heuristic` (по умолчанию), `surprisal` (однородный фон), `attention` (смешанный контент).
- **slice** — видео режется на последовательные клипы 45–60 с без пропусков и перекрытий, каждый становится отдельным шортом
  (не более `max_clips` на видео).

## Качество видео и «рывки» между кадрами

Откуда берутся рывки и чем они лечатся (все параметры в `config.ini`, у каждого есть флаг командной строки):

| Проблема | Что делает программа | Параметры |
|----------|----------------------|-----------|
| Слишком много коротких кусков, картинка «дёргается» | Выбирает самые сильные сегменты вместо нарезки всех подряд, отбрасывает мелкие, ограничивает число склеек | `min_segment_seconds`, `max_segments`, `selection`, `median_seconds`, `merge_gap_seconds` |
| Хайлайт получился слишком коротким | Добавляет контекст вокруг найденных моментов до целевой длины | `fill_to_target`, `target_seconds` |
| Срез посреди слова или фразы | Сдвигает каждый срез на ближайшую паузу в звуке | `snap_seconds` |
| Щелчки звука на стыках | Микро-затухание звука на каждом срезе | `audio_fade_ms` |
| Жёсткие склейки между сегментами | Умные переходы (см. ниже) | `transition`, `transition_style`, `transition_seconds` |
| Дрожание картинки (24/25/60 кадров принудительно в 30) | Сохраняется частота кадров исходника | `fps = source` (или число) |
| Потеря качества при пересжатии | Единые настройки кодирования на всех шагах, включая субтитры | `quality`, `crf`, `preset`, `audio_bitrate_kbps` |
| Мягкая картинка после масштабирования | Масштабирование Lanczos и опциональная резкость | `sharpen` |

**Профили `quality`:** `draft` (быстро, мало места), `standard`, `high` (по умолчанию), `max` (лучшее качество, медленнее).
`crf` (0–51, меньше = лучше и больше файл) и `preset` переопределяют профиль.

**«Насколько резкое видео будет» и «насколько оно разделено»:**

- `threshold` — чувствительность: меньше значение, больше и длиннее моменты «действия»; больше — только самые резкие пики.
- `weight_motion`, `weight_flow`, `weight_loudness`, `weight_audio_change` — что считать динамикой: изменение картинки, движение,
  громкость или резкие изменения звука (веса относительные, 0 отключает сигнал). Для разговорного ролика поднимите `weight_loudness`,
  для спорта и игр — `weight_motion` и `weight_flow`.
- `median_seconds`, `smoothing_window`, `analysis_window_seconds`, `min_activity_seconds`, `sample_fps` — сглаживание и точность анализа.
- `max_segments` и `min_segment_seconds` — на сколько кусков разделён хайлайт и как коротки они могут быть.
  В режиме `slice` длину кусков задают `min_clip_seconds` и `max_clip_seconds`.

## Умные переходы

Между сегментами хайлайта программа сама определяет, какой переход нужен, и **предлагает его вам с объяснением**.
Правила построены на статье [Clipchamp о переходах](https://clipchamp.com/ru/blog/video-transitions-transform-video-editing/):
переход должен соответствовать настроению и темпу, затирания и вытеснения подчёркивают смену места или темы, «через чёрное»
даёт паузу, энергичные эффекты нужны редко, а повторять один и тот же эффект подряд не стоит.

Для каждого стыка измеряется: сколько секунд исходника между моментами, насколько похожи кадры по цвету, яркость,
движение и громкость с обеих сторон. Из этого выбирается переход и длительность (0.15–0.9 с: быстрее при высокой энергии,
короче при речи, чтобы звуки не накладывались). Общий темп материала (`calm` / `neutral` / `dynamic`) определяется автоматически
и ограничивает число «ярких» эффектов; два ярких эффекта подряд не ставятся.

Пример предложения в терминале:

```
  Предлагаемые переходы (темп материала: neutral):

   №  стык в исходнике  переход                     сек  причина
  --  ---------------- -------------------------- ----  ----------------------------------------
   1  1:12 -> 3:40     Вытеснение вверх           0.31  Смена места или темы: вытеснение; высокая энергия
   2  3:58 -> 6:15     Исчезание через чёрное     0.54  После яркого момента нужна пауза

  Enter = принять  |  2=zoom  |  2=alt (другой вариант)  |  3=pushup:0.3  |  all=fade  |  list = все переходы
```

Режимы (`transition` в `config.ini` или `--transition`):

| Значение | Что происходит |
|----------|----------------|
| `ask` (по умолчанию) | Программа предлагает план, вы жмёте Enter или правите. Без терминала работает как `auto` |
| `auto` | Тот же анализ, без вопросов |
| `cut` | Только прямые склейки |
| любое имя из таблицы ниже | Один и тот же переход на всех стыках |

Правки в диалоге: `2=zoom` (стык 2), `2=zoom:0.5` (с длительностью), `2=alt` (следующая альтернатива программы), `all=fade`
(везде), `list` (весь каталог). Темп можно задать вручную: `transition_style = calm | neutral | dynamic`, длительность: `transition_seconds`.

| Имя | Переход | Аналог в Clipchamp |
|-----|---------|--------------------|
| `fade` | Плавное растворение | Затухание при переходе |
| `dissolve` | Зернистое растворение | Затухание при переходе |
| `blur` | Размытие при переходе | Размытие при переходе |
| `fadeblack`, `fadewhite` | Исчезание через чёрное / белое | Исчезание через чёрное / белое |
| `wipeleft`, `wiperight`, `wipeup` | Затирание | Затирание влево / вправо |
| `pushup`, `pushdown`, `pushleft`, `pushright` | Вытеснение | Вытеснение влево / вправо / вверх / вниз |
| `zoom` | Увеличение | Увеличение |
| `pixelize` | Пикселизация | Пикселизация |
| `diagonal` | Мягкая шторка по диагонали | Мягкая шторка по диагонали |
| `blinds` | Жалюзи | Жалюзи |
| `reveal` | Раскрытие | Раскрытие |
| `radial`, `circle` | Вращательное затирание, расходящийся круг | Вращение и Цветение (приближённо) |
| `cut` | Прямая склейка | — |

Эффекты, которым нужна графика (Сгорание, Огонь, Сердечко, Переворот страницы, Жидкие капли, Помехи, Коллаж, Обмен), в ffmpeg
готовых аналогов не имеют и не включены. Переходы относятся только к режиму `highlight`: в режиме `slice` шорты не склеиваются.

## config.ini

| Раздел | Параметр | Значение |
|--------|----------|----------|
| `[paths]` | `input_dir`, `music_dir`, `output_dir`, `work_dir` | Папки. Относительные считаются от папки с `config.ini`, `~` раскрывается |
| `[pipeline]` | `mode` | `highlight` или `slice` |
| | `variant`, `target_seconds`, `threshold`, `buffer_seconds`, `merge_gap_seconds` | Параметры режима highlight |
| | `min_clip_seconds`, `max_clip_seconds`, `max_clips` | Параметры режима slice |
| | `vertical` | `blur` (кадр целиком на размытом фоне), `crop` (на весь экран), `off` |
| `[highlight]` | `weight_*`, `analysis_window_seconds`, `min_activity_seconds`, `smoothing_window`, `median_seconds`, `sample_fps`, `min_segment_seconds`, `max_segments`, `selection`, `fill_to_target` | Тонкая настройка поиска динамики и сборки хайлайта (см. выше) |
| `[cuts]` | `snap_seconds`, `audio_fade_ms`, `transition`, `transition_style`, `transition_seconds` | Срезы и переходы |
| `[video]` | `quality`, `crf`, `preset`, `fps`, `sharpen`, `audio_bitrate_kbps` | Качество кодирования |
| `[subtitles]` | `enabled`, `language`, `brand_kit`, `whisper_model` | Язык `auto`/`en`/`ru`; стили `viral_yellow`, `neon_blue`, `fire_red`, `minimal_white`, `gradient_purple` |
| `[music]` | `enabled`, `volume` | Громкость музыки 0.0–1.0 |

Комментарии после `#` разрешены. Путь не должен содержать ` #` или ` ;` (с пробелом перед ними).

## Параметры командной строки

Любой параметр переопределяет `config.ini` только для этого запуска.

```bash
python main.py --list                                   # только показать список
python main.py --case all                               # обработать всё без вопросов
python main.py --case 2-4 --mode slice --no-music
python main.py --input-dir D:\Raw --output-dir D:\Shorts --music-dir D:\Music --case all
python main.py --case 1 --mode highlight --target 45 --variant attention
python main.py --case all --force                       # переделать уже обработанные
python main.py --config my_other_config.ini
python main.py --ask-folders                            # спросить папки при запуске
python main.py --case 1 --quality max --sharpen 0.4     # лучшее качество и лёгкая резкость
python main.py --case 1 --max-segments 3 --min-segment 8 --transition auto   # меньше склеек, переходы без вопросов
python main.py --case 1 --weights 0.2,0.2,0.5,0.1       # динамика по громкости речи
python main.py --case 1 --transition pushup --transition-sec 0.3
```

`python main.py --help` показывает все флаги. Код возврата: 0 — успех (в том числе когда во входной папке нет видео), 1 — хотя бы одно видео не обработалось, 2 — неверные настройки или несуществующая папка.

## Журнал обработки

В `output_dir/processing_log.json` запоминается, какие видео уже сделаны (имя, размер, дата изменения, режим). Повторный запуск
пропускает их. Файл переделывается, если исходник изменился, готовый результат удалён или выбран другой режим. Изменили качество, переходы или веса? Добавьте `--force`: журнал их не учитывает. Флаг `--force`
обрабатывает всё заново. Ошибка на одном видео не останавливает остальные.

## Заметки

- Первый запуск с субтитрами скачивает модель Whisper (для `medium` около 1.5 ГБ). Без видеокарты NVIDIA минутный клип занимает
  порядка 1–2 минут; для скорости поставьте `whisper_model = small` или `base`.
- Субтитры определяют только английский и русский язык. Если речи или звуковой дорожки нет, субтитры пропускаются с пометкой.
- На равномерном видео режим highlight может дать клип короче цели. Тогда уменьшите `threshold` или используйте `slice`.
- Используйте только видео и музыку, на которые у вас есть права.

```
main.py                  точка входа, в начале блок с вашими папками
config.ini               настройки и папки
video_maker/
  cli.py                 меню, флаги, итоговая сводка
  batch.py               список видео, выбор, журнал, пакетный запуск
  config.py              чтение config.ini, параметры пайплайна
  pipeline.py            резка -> 9:16 -> субтитры -> музыка
  ffmpeg_utils.py        резка, вертикальный формат, склейка, переходы, настройки кодирования
  slicer.py              план нарезки
  audio_mix.py           микс музыки
  snap.py                привязка срезов к паузам в звуке
  transitions.py         анализ стыков, выбор переходов, правки пользователя

  highlights/            поиск динамичных моментов
  subtitles/             Whisper, рендер субтитров, стили
```
